# Airline Reservation System

A frontend-based Airline Reservation System built with **HTML, CSS and JavaScript** as part of my BCA project.

## Features
- Login and Registration pages
- Flight booking form (From, To, Date, Class)
- Seat selection (50 seats)
- Payment page (UPI, Credit Card, Debit Card, Net Banking)
- Booking confirmation receipt

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)

## How to Run
Open `index.html` in any web browser. No installation or server required.

## How to Use
1. Click **Register** and enter your name and mobile number.
2. Login with any email and password.
3. Fill in the booking details and select a seat.
4. Choose a payment method and view the booking receipt.
